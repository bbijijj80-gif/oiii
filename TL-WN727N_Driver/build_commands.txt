================================================================================
КОМАНДЫ ДЛЯ СБОРКИ ДРАЙВЕРА В EWDK (x64) И ПОДПИСАНИЯ (SIGNING)
TP-LINK TL-WN727N v5.20 Driver for Windows Server 2019
================================================================================

ТРЕБОВАНИЯ:
- Windows 10/11 или Windows Server 2019 с установленным EWDK (Enterprise WDK)
- Visual Studio 2019 или новее с поддержкой WDK
- Сертификат для подписи драйвера (самоподписанный или от доверенного CA)

--------------------------------------------------------------------------------
ШАГ 1: ПОДГОТОВКА ОКРУЖЕНИЯ EWDK
--------------------------------------------------------------------------------

# Запустите командную строку EWDK (от имени администратора):
C:\EWDK\10.0.17763.1\BuildEnv\LaunchBuildEnv.cmd

# Или для более новой версии EWDK:
C:\EWDK\WS2019\10.0.17763\BuildEnv\LaunchBuildEnv.cmd

--------------------------------------------------------------------------------
ШАГ 2: НАВИГАЦИЯ К ПРОЕКТУ
--------------------------------------------------------------------------------

cd /d C:\path\to\TL-WN727N_Driver

--------------------------------------------------------------------------------
ШАГ 3: СБОРКА ДРАЙВЕРА ЧЕРЕЗ MSBUILD
--------------------------------------------------------------------------------

# Сборка Release x64 версии:
msbuild rtl8188eu.vcxproj /p:Configuration=Release /p:Platform=x64 /p:WindowsTargetPlatformVersion=10.0.17763.0

# Альтернативная команда с полным путем к toolset:
msbuild rtl8188eu.vcxproj ^
    /p:Configuration=Release ^
    /p:Platform=x64 ^
    /p:WindowsTargetPlatformVersion=10.0.17763.0 ^
    /p:PlatformToolset=WindowsApplicationForDrivers10.0 ^
    /t:Build ^
    /v:minimal

--------------------------------------------------------------------------------
ШАГ 4: ПРОВЕРКА РЕЗУЛЬТАТОВ СБОРКИ
--------------------------------------------------------------------------------

# После успешной сборки файлы будут расположены в:
# .\x64\Release\rtl8188eu.sys
# .\x64\Release\rtl8188eu.inf
# .\x64\Release\rtl8188eu.cat (если настроено создание каталога)

dir x64\Release\*.sys
dir x64\Release\*.inf

--------------------------------------------------------------------------------
ШАГ 5: СОЗДАНИЕ САМОПОДПИСАННОГО СЕРТИФИКАТА (ЕСЛИ НЕТ ГОТОВОГО)
--------------------------------------------------------------------------------

# Создание самоподписанного сертификата для тестирования:
makecert -r -pe -ss PrivateCertStore -n CN=TestDriverCert TestDriverCert.cer

# Или используя PowerShell:
powershell -Command "New-SelfSignedCertificate -Subject 'CN=TestDriverCert' -CertStoreLocation Cert:\LocalMachine\My -Type CodeSigning"

--------------------------------------------------------------------------------
ШАГ 6: ПОДПИСАНИЕ ДРАЙВЕРА (SIGNING)
--------------------------------------------------------------------------------

# Вариант A: Подпись с помощью SignTool (рекомендуется)
signtool sign /v /fd SHA256 /f TestDriverCert.pfx /t http://timestamp.digicert.com x64\Release\rtl8188eu.sys

# Вариант B: Подпись с указанием хранилища сертификатов
signtool sign /v /fd SHA256 /s My /n "TestDriverCert" /t http://timestamp.digicert.com x64\Release\rtl8188eu.sys

# Подписание INF-файла:
signtool sign /v /fd SHA256 /f TestDriverCert.pfx /t http://timestamp.digicert.com x64\Release\rtl8188eu.inf

--------------------------------------------------------------------------------
ШАГ 7: СОЗДАНИЕ КАТАЛОГА БЕЗОПАСНОСТИ (CATALOG FILE)
--------------------------------------------------------------------------------

# Создание .cat файла для пакета драйвера:
inf2cat /driver:x64\Release /os:Server2019_x64,10_10_x64 /verbose

# Или с явным указанием пути:
inf2cat /v /path:"C:\path\to\TL-WN727N_Driver\x64\Release" /os:Server2019_x64

# Подписание каталога:
signtool sign /v /fd SHA256 /f TestDriverCert.pfx /t http://timestamp.digicert.com x64\Release\rtl8188eu.cat

--------------------------------------------------------------------------------
ШАГ 8: ПРОВЕРКА ПОДПИСИ
--------------------------------------------------------------------------------

# Проверка подписи драйвера:
signtool verify /v /kp x64\Release\rtl8188eu.sys

# Проверка подписи каталога:
signtool verify /v /kp x64\Release\rtl8188eu.cat

--------------------------------------------------------------------------------
ШАГ 9: УСТАНОВКА ДРАЙВЕРА (ДЛЯ ТЕСТИРОВАНИЯ)
--------------------------------------------------------------------------------

# Отключение проверки подписи драйверов (только для тестирования!):
bcdedit /set testsigning on
bcdedit /set nointegritychecks on
# Перезагрузите систему после выполнения этих команд

# Установка драйвера через pnputil:
pnputil /add-driver x64\Release\rtl8188eu.inf /install

# Или через диспетчер устройств:
# 1. Откройте devmgmt.msc
# 2. Найдите устройство с USB\VID_2357&PID_010C
# 3. Обновите драйвер, указав путь к x64\Release\

--------------------------------------------------------------------------------
ШАГ 10: ВКЛЮЧЕНИЕ ПРОВЕРКИ ПОДПИСИ (ПРОДАКШН)
--------------------------------------------------------------------------------

# После установки подписанного драйвера отключите тестовый режим:
bcdedit /set testsigning off
bcdedit /set nointegritychecks off
# Перезагрузите систему

================================================================================
ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ И УТИЛИТЫ
================================================================================

dumpbin /headers x64\Release\rtl8188eu.sys

# Анализ зависимостей:
depends.exe x64\Release\rtl8188eu.sys

# Проверка соответствия требованиям WHQL (опционально):
hlk.exe run /project:<ProjectName> /machine:<MachineName>

# Очистка проекта:
msbuild rtl8188eu.vcxproj /t:Clean /p:Configuration=Release /p:Platform=x64

# Пересборка с нуля:
msbuild rtl8188eu.vcxproj /t:Rebuild /p:Configuration=Release /p:Platform=x64

================================================================================
ВАЖНЫЕ ЗАМЕЧАНИЯ
================================================================================

1. Для Windows Server 2019 требуется подпись драйвера с использованием 
   сертификата, доверенного Microsoft (для продакшена) или включенный 
   тестовый режим (для разработки).

2. VID/PID для TL-WN727N v5.20:
   - Vendor ID:  0x2357 (TP-LINK)
   - Product ID: 0x010C (RTL8188EUS chipset)

3. Этот драйвер является базовой реализацией NDIS 6.0 мини-драйвера.
   Для полноценной работы необходимо реализовать:
   - USB-коммуникацию с устройством
   - Работу с буферами приема/передачи
   - Обработку прерываний
   - Управление питанием

4. Для получения сертификации WHQL необходимо пройти тестирование 
   в Microsoft HLK (Hardware Lab Kit).
