================================================================================
Команды для сборки драйвера TP-LINK TL-WN727N v5.20 (RTL8188EU) в EWDK x64
Целевая платформа: Windows Server 2019 x64
Подпись драйвера: ОТКЛЮЧЕНА
================================================================================

ШАГ 1: Запуск среды EWDK
-------------------------
Запустите командную строку EWDK от имени администратора:
  - Найдите LaunchBuildEnv.cmd или SetupEnvironment.cmd в папке EWDK
  - Запустите его (двойной клик или из командной строки)
  
Это создаст специальную командную строку с настроенными переменными окружения:
  - DDK_INC_PATH - пути к заголовочным файлам
  - DDK_LIB_PATH - пути к библиотекам
  - TargetPlatformVersion - версия платформы

ШАГ 2: Переход в папку проекта
-------------------------------
В открывшемся окне "EWDK Command Prompt" выполните:
  cd "C:\Users\newuser\Downloads\oiii-windows-server-2019-driver-development-5613f\oiii-windows-server-2019-driver-development-5613f\TL-WN727N_Driver"

ШАГ 3: Сборка драйвера (Release, x64, БЕЗ ПОДПИСИ)
----------------------------------------------------
Выполните команду:
  msbuild rtl8188eu.vcxproj /p:Configuration=Release /p:Platform=x64 /p:SignMode=Off /p:RunCodeAnalysis=false

Примечание: Параметры SignMode=Off и DriverSign=False уже установлены в vcxproj файле.

ШАГ 4: Проверка результатов сборки
-----------------------------------
После успешной сборки файлы появятся в папке:
  x64\Release\rtl8188eu.sys  - файл драйвера
  x64\Release\rtl8188eu.inf  - INF-файл для установки

ШАГ 5: Установка драйвера (опционально)
----------------------------------------
Для установки драйвера вручную:
  1. Откройте Диспетчер устройств (devmgmt.msc)
  2. Найдите устройство TP-LINK TL-WN727N (может быть как неизвестное устройство)
  3. Правый клик -> Обновить драйвер
  4. Выберите "Выполнить поиск драйверов на этом компьютере"
  5. Укажите путь к папке x64\Release
  6. Нажмите "Все равно установить этот драйвер" (так как подпись отключена)

ИЛИ используйте команду pnputil:
  pnputil /add-driver "x64\Release\rtl8188eu.inf" /install

================================================================================
ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ (если потребуется подпись в будущем)
================================================================================

Создание самоподписанного сертификата:
  makecert -r -pe -ss PrivateCertStore -n CN=TestDriverCert TestDriverCert.cer

Экспорт сертификата в PFX:
  certutil -exportPFX -p "" My TestDriverCert TestDriverCert.pfx

Подпись драйвера (если потребуется):
  signtool sign /fd SHA256 /f TestDriverCert.pfx /t http://timestamp.digicert.com x64\Release\rtl8188eu.sys

Создание каталога безопасности:
  inf2cat /driver:x64\Release /os:Server2019_x64 /useLocalTime

Проверка подписи:
  signtool verify /kp /v x64\Release\rtl8188eu.sys
